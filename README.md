# Equipo de Ventas con Agentes IA

Plataforma digital de enseñanza que presenta el libro de forma dinámica
(lector por capítulos con progreso de lectura) junto con sus materiales
de práctica.

- **Agencia Productora:** UnoEsMarketing — Performance First
- **Desarrollador:** Erling Sánchez

## Acceso

Portal con 3 días de prueba gratuita. Después, el acceso completo se activa
con un pago único de $10 USD vía PayPal; tras el pago, el lector recibe un
código de acceso que desbloquea la plataforma en su navegador.

## Estructura

| Ruta | Contenido |
|---|---|
| `index.html` | Plataforma de estudio (portada, lector, prácticas y créditos) |
| `gate.js` | Portal de acceso: prueba de 3 días, pago y código de desbloqueo |
| `data.js` | Libro completo segmentado en capítulos + recursos embebidos |
| `app/` | Aplicación y materiales originales del paquete |

27 capítulos · edición de estudio 2026 · Sitio estático sin dependencias:
funciona en GitHub Pages o en cualquier hosting.
